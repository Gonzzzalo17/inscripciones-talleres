# Pruebas (pytest)

Aquí van todas las pruebas. Se ejecutan con `python -m pytest`.

- Un archivo por cada archivo de lógica: `inscripciones/servicios/operador.py` → `tests/test_operador.py`.
- Las pruebas verifican reglas (cupo, espera, cancelación), no el HTML.
- `version_inicial/` contiene las pruebas de la primera versión (sesiones 4 y 12).
